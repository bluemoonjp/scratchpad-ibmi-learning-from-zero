## なぜ学ぶか

ここまでのプログラムは、上から下へ一本道で実行されるだけでした。ここで初めて、**条件によって処理を分ける**ことを学びます。

## 新出

- `IF`(CL では **コマンド**であり、`F4` でプロンプトできる)
- `*EQ`・`*NE` などの比較演算子(記号ではなく略語を使う理由)
- `DO`/`ENDDO`(処理のまとまり)

## 説明

### IF はコマンド

多くの言語では `if` は言語の構文の一部ですが、**CL の `IF` は、他のコマンドと同じ「コマンド」です。** そのため、`IF` とだけ打って `F4` を押せば、プロンプト画面が開きます。

### 比較に記号ではなく略語を使う理由

CL では `=`・`<>` のような記号ではなく、`*EQ`(等しい)・`*NE`(等しくない)・`*GT`(より大きい)のような略語を使います。00-01 で触れたとおり、IBM i の内部は EBCDIC 系の文字コードで、一部の記号(`|`・`~`・`^` など)は表示環境によって化けることがあります。**略語を使えば、コード・ページの違いに影響されにくい**という利点があります。

### DO は「まとまり」であって「繰り返し」ではない

他の言語の経験があると、`DO` を見て「繰り返し(ループ)」を連想するかもしれませんが、**CL 単体の `DO`/`ENDDO` は、複数のコマンドをひとまとめにするためのもの**で、繰り返しではありません。繰り返しは、次のレッスン(03-05)で学ぶ `DOWHILE` などの別のコマンドを使います。

## 実演

1. `WRKMBRPDM FILE(<自分のユーザー名>1/QCLSRC)` で `C0304A`(`CLP`)を作る。
2. 次を入力する(`src/qclsrc/c0304s.clp` と同じです)。

   ```clp
   PGM
   DCL        VAR(&LIB) TYPE(*CHAR) LEN(10) VALUE('QSYS2')

   IF         COND(&LIB *EQ 'QSYS') THEN(DO)
      SNDPGMMSG  MSG('This is the system library.')
   ENDDO
   ELSE       CMD(DO)
      SNDPGMMSG  MSG('This is not QSYS.')
   ENDDO

   ENDPGM
   ```

3. コンパイル・実行し、`DSPJOBLOG` でどちらのメッセージが出たか確認する。

## 同じ手順を別の対象で

`&LIB` の初期値を `'QSYS'` に変えて再コンパイル・実行し、もう一方の枝が実行されることを確認してください。

## 演習

`IF`/`ELSE` を入れ子(ネスト)にして、`&LIB` が `'QSYS'`・`'QSYS2'`・それ以外、の3通りを判定するプログラムを書いてください(`ELSE` の中にもう1つ `IF` を書く形になります)。
