## なぜ学ぶか

文字型だけでは、計算や条件分岐を伴うプログラムは書けません。ここで数値・論理型と、文字列を組み立てる3通りの連結方法を身につけます。

## 新出

- `*DEC`(10進数)・`*LGL`(論理値)・`*INT`(整数)
- `*CAT`・`*TCAT`・`*BCAT`(3種類の連結)
- `%SST`(部分文字列)・`%TRIM`(空白の除去)

## 説明

### 3種類の連結

| 演算子 | 動作 |
|---|---|
| `*CAT` | そのまま連結する(左側の変数の末尾の空白も含まれる) |
| `*TCAT` | 左側の末尾の空白を取り除いてから連結する(詰めて連結) |
| `*BCAT` | 左側の末尾の空白を取り除き、**空白を1つ入れて**連結する |

`*CHAR LEN(10)` の変数に `'TARO'` を入れると、実際には `'TARO      '`(6個の空白で埋められている)という状態になります。これをそのまま `*CAT` で連結すると、余分な空白が挟まります。名前と名字をきれいにつなげたいときは `*TCAT` や `*BCAT` を使います。

**注意**: CCSID 273(PUB400 のコード・ページ)では、縦棒(`|`)の見た目が変わることがあります(00-03 で触れた可変文字の1つです)。ソース・コードの中で縦棒を使う場面は少ないですが、もし見慣れない記号に見えたら、この可変文字の話を思い出してください。

### %SST と %TRIM

`%SST(&変数 開始位置 長さ)` で、変数の一部分を取り出せます(部分文字列)。`%TRIM(&変数)` は、前後の空白を取り除きます。

## 実演

1. `WRKMBRPDM FILE(<自分のユーザー名>1/QCLSRC)` で `C0303A`(`CLP`)を作る。
2. 次を入力する(`src/qclsrc/c0303s.clp` と同じです)。

   ```clp
   PGM
   DCL        VAR(&FIRST) TYPE(*CHAR) LEN(10) VALUE('TARO')
   DCL        VAR(&LAST) TYPE(*CHAR) LEN(10) VALUE('YAMADA')
   DCL        VAR(&MSG1) TYPE(*CHAR) LEN(30)
   DCL        VAR(&MSG2) TYPE(*CHAR) LEN(30)
   DCL        VAR(&MSG3) TYPE(*CHAR) LEN(30)

   CHGVAR     VAR(&MSG1) VALUE(&FIRST *CAT &LAST)
   CHGVAR     VAR(&MSG2) VALUE(&FIRST *TCAT &LAST)
   CHGVAR     VAR(&MSG3) VALUE(&FIRST *BCAT &LAST)

   SNDPGMMSG  MSG('CAT  =[' *TCAT &MSG1 *TCAT ']')
   SNDPGMMSG  MSG('TCAT =[' *TCAT &MSG2 *TCAT ']')
   SNDPGMMSG  MSG('BCAT =[' *TCAT &MSG3 *TCAT ']')
   ENDPGM
   ```

3. コンパイル・実行し、`DSPJOBLOG` で3つのメッセージを見比べる。`CAT` は間に大きな空白、`TCAT` は空白なし、`BCAT` は空白1つ、という違いが見えるはずです。

## 同じ手順を別の対象で

`&FIRST`/`&LAST` の値を、自分で考えた別の2つの単語に変えて、同じ違いを確認してください。

## 演習

1. `*DEC` 型の変数を2つ宣言し(`DCL VAR(&A) TYPE(*DEC) LEN(5 0) VALUE(10)` のように)、`CHGVAR` で加算した結果を3つ目の変数に入れ、`SNDPGMMSG` で表示してください。
2. `%SST(&LAST 1 3)` で、`&LAST`(`'YAMADA    '`)の最初の3文字を取り出し、表示してください。
3. `%TRIM(&LAST)` の結果と、`&LAST` そのままの結果を、それぞれ `*TCAT` で `'['`・`']'` に挟んで表示し、違いを確認してください。
