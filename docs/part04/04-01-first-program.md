## なぜ学ぶか

CL では「1件ずつ読むことしかできない」という壁に、03-09 でぶつかりました。**RPG は、ファイルを効率よく読み書きするために作られた言語**です。多くの企業の基幹システムで、今も現役で動いている RPG III のコードを、**読んで保守できるようになる**(第5部)ための土台として、まずは小さなプログラムを自分で書きます。

## 新出

- RPG/400(OPM)と RPG IV の関係
- 仕様書の順序: H(制御)・F(ファイル記述)・E(拡張)・L(行カウンター)・I(入力)・C(演算)・O(出力)
- 6桁目(仕様書の種類)、7桁目の `*`(コメント)
- 名前は6文字以内

## 説明(Windows / Linux との比較)

RPG(Report Program Generator)は、その名のとおり「レポート(帳票)を作るためのプログラム」として生まれました。今学ぶ **RPG III**(別名 RPG/400)は、1988年に登場した、AS/400(IBM i の前身)向けの世代です。もっと新しい **RPG IV**(1994年〜、第6部で学びます)とは別物で、書き方も大きく異なります。**RPG III には EVAL のような自由な代入式や、D 仕様書、サブプロシージャがありません。** 今のプログラミング言語に慣れていると、かなり窮屈に感じるはずです。

### 仕様書の順序

RPG III のソースは、次の順で書きます(使わない種類は省略できます)。

| 仕様書 | 役割 |
|---|---|
| H | 制御(プログラム全体の設定) |
| F | ファイル記述(使うファイルの宣言) |
| E | 拡張(配列・表) |
| L | 行カウンター(帳票の1ページの行数) |
| I | 入力(ファイルのフィールド定義、改名) |
| C | 演算(実際の処理) |
| O | 出力(帳票・画面への出力) |

**6桁目が、その行がどの仕様書かを表します**(`H`・`F`・`C`・`O` など)。**7桁目に `*` を書くと、桁6の内容に関わらず、その行全体がコメント**として扱われます。

### 名前は6文字以内

RPG III のフィールド名・変数名は、**6文字以内**という制限があります(02-01 で、サンプル・データベースのフィールド名をすべて6文字以内にした理由です)。

## 実演

1. `WRKMBRPDM FILE(<自分のユーザー名>1/QRPGSRC)` を開く(01-06 で作成済みのはずです)。`F6` で `R0401A`(ソース・タイプ `RPG`)を作る。
2. 次を、桁位置に注意しながら入力する(`src/qrpgsrc/r0401s.rpg` と同じ内容です)。

   ```text
   ....+....1....+....2....+....3....+....4....+....5....+....6....+....7....+....8
         * R0401A - minimal RPG III: print one line via EXCPT.
        H
        FQSYSPRT O   F     132            PRINTER
        C                     EXCPT
        C                     SETON                     LR
        OQSYSPRT E
        O                                   20 'HELLO, RPG III!'
   ```

   1行目はコメント(7桁目に `*`)、2行目は H 仕様書(制御。今回は特別な設定なし)、3行目は F 仕様書(`QSYSPRT` という印刷装置ファイルを、プログラム記述で宣言)、4〜5行目は C 仕様書(`EXCPT` で出力をトリガーし、`SETON LR` でプログラムを終了)、6〜7行目は O 仕様書(`E`=例外出力。文字列を印刷装置の20桁目までに出力)です。

3. `F3` で保存し、`WRKMBRPDM` の一覧でオプション `14`(コンパイル)を実行する。
4. コンパイルが成功したら `CALL PGM(R0401A)` を実行する。
5. `WRKSPLF` で、`HELLO, RPG III!` と印刷されたスプールを確認する。

## 演習

1. 出力する文字列を、自分の好きな文言に変えて、再コンパイル・実行してください。
2. `20`(終了位置)の値を `40` に変えて、文字列が印刷される位置がどう変わるか確認してください。
