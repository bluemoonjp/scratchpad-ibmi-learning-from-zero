# 第4部V 固定形式 RPG IV を書く・読む(RPG III を通らないルート)

この部は、**RPG III を学ばずに第6部へ進む人のための、第4部・第5部の代わり**です。第4部(RPG III を書く)と第5部(RPG III を読む・直す)を通る人は、この部を読む必要はありません。通常の一本道は、この部があっても変わりません。

## 誰がこの部を使うか

次の両方に当てはまる人が対象です。

- 職場の RPG が、**`CRTBNDRPG` でコンパイルする RPG IV**(固定形式、または固定形式と `/FREE` の混在)である。
- RPG III(`CRTRPGPGM`、RPG/400)を、これから先も書かない・読まない。

**`CRTRPGPGM` でコンパイルしている職場は、この部の対象外です。** それは RPG III そのものなので、第4部・第5部を通ってください。

迷ったときの目安です。

| 職場の状況 | 進むルート |
|---|---|
| `CRTBNDRPG`(ILE)だけを使っている | この部(第4部V) |
| `CRTRPGPGM`(OPM、RPG III)のプログラムを保守する | 第4部・第5部(一本道) |
| 両方ある | 第4部・第5部(一本道)。RPG III を読めないと困るため |

## この部の目標

固定形式の RPG IV で、小さなプログラムを自分で書き、既存のものを読めるようになります。仕様書の桁位置、標識、外部記述ファイル、`CALL`/`PARM`、サイクル、表示装置ファイルを扱います。第6部以降が前提にしている準備(道具と旧システムの用意)も、この部の中の1本(04-27)で済ませます。

## 番号が飛んでいる理由

レッスン番号は **`04-21` から `04-28` まで**です。`04-14`〜`04-20` は**意図的な欠番**で、書き忘れではありません。理由は3つです。

- この教材の命名規則は「部2桁+課2桁」です(オブジェクト名も同じ形で、`V0421A` のようになります)。第4部の `04-01`〜`04-13` と重ならない番号にしたいので、`04-21` から始めます。
- `TXCKM`(`TXCHECK` が読むチェックの一覧表)の `LESSON` 欄は6文字(`6A`)です。`04-21` のような5桁の番号も、`06-11b` のような枝番の番号と同じ欄に収まります。
- `b` の付く枝番は「任意の寄り道」という意味で使っているので、この部では使いません。

## 全体の流れ

この部を通る人の鎖は、次のとおりです。

```text
第3部(03-14) → 04-21 … 04-28 → 06-01b → 06-02 → …
```

- **06-01 は行いません。** 06-01 は RPG III の `R0408A` を `CVTRPGSRC` で変換する回です。同じ `V0601A` は 04-27 の手順 A3 で作ります。
- **第5部は通りません。** 第5部で作る道具(`TXCHECK`・`TXSNAP`)と旧システムは、04-27 で用意します。05-07(影響調査)の核は 04-28 で扱います。
- 第6部以降の各レッスンで、ルート上の前提・準備・読み替えがどうなるかは、[ロードマップ](../roadmap.md#rpg-iii-を通らないルート固定形式-rpg-iv-の職場向け)の対応表にまとめています。

## 前提となる状態

- 第3部まで(特に [03-14](../part03/03-14-checkpoint-backup.md))が済んでいること。
- 第2部の `TXSETUP` でサンプル・データベース(`TOKUIM`・`JUCHUM`・`JUCHUD`・`ZAIKOM` など)が入っていること。`TXSTATUS` で確認してください。
- 教材のソース一式を `git clone` してあること([02-04](../part02/02-04-ssh-git-clone.md))。

## 道具

5250(PDM/SEU、仕様書ごとの `F4` プロンプト)。SEU が `**FREE` を正しく扱えないという注意があるため、04-21 で SEU と Code for IBM i のどちらで編集するかを選びます。04-24 以降は SQL(`HEX()` など)も使います。

## 観測方法

`WRKSPLF`(帳票もコンパイル・リストも同じ場所に出ます)、`DSPJOBLOG`。画面は画面そのものを見ます。

## この部で扱わないこと

- RPG III(`CRTRPGPGM`)。
- 完全自由形式(`**FREE`)。第6部で扱います。
- サブファイル・配列・データ構造を**自分で設計して書く**こと(読むだけです)。

## 同時接続数

5250×1(04-23 の演習の一部だけ、バッチ・ジョブを1本投入します)。

## 見本のオブジェクト名

- 学習者が自分で書くオブジェクトは `V042x` の形(`V0421A` など)、配布の見本は `S`〜`Z`(`v0421s.rpgle` など)です。命名の決まりは[付録E](../appendix/e-naming.md)を参照してください。
- どの見本も、第4部の RPG III 版(`R0408A` など)と**同じ出力**になるように作ってあります。第6部が比較に使う `R04xx` を、`V04xx` に読み替えられるようにするためです。

## 検証の状態

**非対話で確認できる範囲は、2026-10-04 に実機(PUB400)で確認しました。** コンパイル・実行・印字・ジョブ・ログのメッセージ ID は、バッチ `part04v-21cmp`・`22cmp`・`23run`・`24run`・`25run`・`26scr`・`27set`・`28imp` を実際に走らせた結果をもとにしています。旧システムの固定形式 RPG IV 版(`src/legacy/qrpgle112/`)も、実機の `CVTRPGSRC` の出力そのままで、印字が RPG III 版と同一であることを確認しました(`part05-lgcvt`・`part05-lggold`)。各レッスンの「実機メモ」に、確認できたことと未検証のことを分けて書いています。

**未検証(2026-10-04時点)なのは、次のものです。**

- 対話でしか確認できない手順: 5250 画面の `EXFMT`、`STRDBG` でのデバッグ、SEU・PDM の操作、2つのセッションを使うレコード・ロックの体験。
- バッチが実行していないもの: 各レッスンの「実機メモ」に「未検証」と書いた、演習の変形や別データでの再実行など。
- `OVRPRTF`/`DLTOVR` と `TXSNAP`(`CPYSPLF`)を使うスプール比較の手順。検証の接続では `CPYSPLF FILE(QSYSPRT)` が `CPF3303` で失敗するため、この取り込みの通しは行っていません。
- 04-27 から第6〜10部へ通して進む確認。[ロードマップ](../roadmap.md)の対応表の各行に、確認できた範囲と残っている範囲を書いています。

未検証のレッスンは、検証が済むまで `main` ブランチに公開しません。
