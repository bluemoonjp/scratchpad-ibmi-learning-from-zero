# 学習記録テンプレート

このファイルをコピーして、自分の学習記録として使ってください(例: `progress.md` という名前でリポジトリーの外、自分のメモ場所に置く)。

## 使い方

- レッスンを終えるごとに、そのレッスンの確認IDを表に追加します。
- 習熟度は3段階です。
  1. 手順書を見ればできる
  2. 見ずにできる
  3. 別の対象に応用でき、日を空けてもできる
- 各部のチェックポイントに合格したら、その部の行にチェックを入れます。
