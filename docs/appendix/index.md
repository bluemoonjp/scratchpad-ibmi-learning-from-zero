# 付録

レッスン本文を横断して参照する、辞書的な資料です。順番に読む必要はありません。第0〜9部の範囲から集めており、第10部の分は、メッセージ ID(付録B)・トラブル(付録C)・名前(付録E)に、2026-09-30の実機確認の範囲で加えました(各ファイル冒頭の注記を参照してください)。

- [付録A 用語](a-glossary.md) — 各レッスンの「まとめ」の英日対訳を1つに集約した用語集。
- [付録B メッセージ ID](b-message-ids.md) — 実機で確認した・していないを明記したメッセージ ID 一覧。
- [付録C トラブル](c-troubleshooting.md) — 症状・原因・確認方法のパターン集。
- [付録D キー対応表](d-keys.md) — レッスン本文に出てきた5250のキーと SEU のキー・行コマンド(確認できた範囲のみ。エミュレーター別の完全な表ではありません)。
- [付録E 命名規則](e-naming.md) — オブジェクト・ライブラリー・道具の命名規則。
- [付録F BIF早見表](f-bif-reference.md) — RPG の組み込み関数一覧。
- [付録G 助けの求め方](g-getting-help.md) — 詰まったときの相談先と、質問・Issue の書き方(貼ってはいけないもの、障害報告書を手本にした例)。
- [付録J 日本語・DBCS](j-dbcs.md) — CCSID・DBCS について、09-02b の実測で確認済みのことと、未検証のこと。

第2部で作るサンプル・データベースの構造など、より詳しい設計資料は[`docs/syllabus.md`](../syllabus.md)や各部の扉ページを参照してください。第10部(総合演習)は[第10部の扉ページ](../part10/index.md)から始まります。
