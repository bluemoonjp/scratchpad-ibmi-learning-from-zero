# 付録B メッセージ ID

**この付録は育っていく文書です。** 本教材は、P38(メッセージ ID の系統的な一括採取プローブ)を、いまも実施していません。ここに載っているのは、あくまで**このリポジトリーがこれまでに実際に書いた・遭遇した・実機で確認したメッセージ ID**の一覧です。第6〜9部のレッスンに出てくる ID も、今回まとめて拾いました(拾ったのは、各レッスンの本文・実機メモ・[docs/probes.md](../probes.md)に出てくるものです。IBM の全メッセージを網羅したものではありません)。各行の確認状況は、根拠にしたレッスン番号(または `docs/probes.md`)を添えて書いています。今後のプローブが進むにつれて、行が増え、`未確認` が `実機確認` に変わっていきます。

## この表の読み方(確認状況の凡例)

各行の「意味」欄の先頭に、次のいずれかの印を付けています。**この印は正直さのための印です。学習の役に立てるためには、どれが「実機で本当に起きたことの記録」で、どれが「まだ確認していない推定」なのかを区別してください。**

| 印 | 意味 |
|---|---|
| **[実機確認]** | [docs/probes.md](../probes.md) に、または該当レッスン自身の「実機メモ」・本文の検証記録に、実際の PUB400 上でこのメッセージ ID が発生した(またはこの ID を意図的に発生させて確認した)という記録がある。根拠が `docs/probes.md` ではなくレッスンだけの行は、行の中でレッスン番号を明記している。 |
| **[条件付き確認]** | 実機で確認はできているが、SSH(PASE の `system()` 経由)でジョブを起動した場合に限られる。5250 の対話的なコマンド行で同じことが起きるかどうかは、まだ確認できていない。 |
| **[未確認]** | 該当レッスンの「実機メモ」が「未確認」「未検証」と明記している、または一次資料・設計段階の推定にとどまり、`docs/probes.md` にも記録が無い。 |
| **[教材独自]** | IBM 標準のメッセージ ID を、このリポジトリー自身のツールが独自の用途で使っている(または、このリポジトリー自身が登録した完全に独自のメッセージ)。 |

**この付録に書いていないこと**: 設計段階で名前だけ挙がっていた `MCH1211` のようなメッセージ ID は、`docs/probes.md` にも、どのレッスンにも実際には一度も登場していません。実在しないものを実在するかのように書くと学習者を誤らせるため、**確認できないメッセージ ID は載せません。** 食い違いに気づいたら [Issue](https://github.com/bluemoonjp/scratchpad-ibmi-learning-from-zero/issues) で教えてください。

## MONMSG の範囲指定について(参考)

`CPF9800` のように末尾を `00` にすると、`CPF9801`〜`CPF9899` までの範囲をまとめて捕まえられます。`CPF0000` は、あらゆる `CPF` メッセージを捕まえる最も広い指定です([03-06](../part03/03-06-monmsg-1.md)/[03-07](../part03/03-07-monmsg-2.md))。ただしこの範囲指定は、`RPG1216`/`RPG0102` のような `CPF` で始まらないメッセージには一切効きません(上記 RPG のセクション参照)。
