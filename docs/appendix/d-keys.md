# 付録D キー対応表

この付録は、レッスン本文に出てきた5250のキーを、出どころのレッスンごとに1か所へ集めたものです。**ここに書いてあるのは、レッスン本文に書かれている範囲だけです。** 5250エミュレーターごとの完全な割り当て表ではありません。載っていないキー・エミュレーターの組み合わせは「未確認」と読んでください。

5250の画面操作は対話操作(V3)にあたり、この教材の検証ハーネスは非対話でしか実機に接続しません([スタイル・ガイド](../style-guide.md)の「V1/V2/V3」の節)。そのため、この付録のキー割り当てはどれも、実機の5250画面で著者が確認したものではありません。確認の根拠は表の「根拠」欄にそれぞれ書きました。

## 1. エミュレーターのキー割り当て(ACS の既定設定)

出典は[00-03](../part00/00-03-first-signon.md)の「主なキー(ACS の場合)」です。

| 5250のキー | ACS での割り当て | 根拠 |
|---|---|---|
| Enter | PC の Enter | 00-03の表。協力してくれた学習者の実測(V3)。著者は未確認 |
| Reset(入力禁止の解除) | 左 Ctrl | 同上 |
| New Line(改行のみ。Field Exit ではない) | 右 Ctrl | 同上 |
| F13〜F24 | Shift+F1〜Shift+F12(F13=Shift+F1、F14=Shift+F2、……、F24=Shift+F12) | 同上。Shift+F1〜F12がF13〜F24に対応するという並びは、00-03の表の記述そのものです |

- 00-03は、これらが**ACSの既定設定によるもの**で、他のエミュレーターやキーボード配列では異なる場合があると書いています。
- **tn5250j のキー割り当ては、この教材では未確認です。** 00-03は tn5250j を初回のパスワード変更にだけ使っており、キー割り当ては載せていません。
- **`SysReq`(システム要求)と `Attn`(アテンション)に対応する PC のキーは、本文のどこにも書かれていません(未確認)。** 使う場面は次の2節に書きました。

## 2. 5250のキーの役割(本文で使っているもの)

| キー | 役割 | 出てくる場所 | 根拠 |
|---|---|---|---|
| Enter | 画面に入力した内容をまとめてホストへ送る | 00-03 | 00-03の説明(5250は画面全体を1単位として送る方式) |
| Reset | 入力禁止状態の解除 | 00-03 | 上の表と同じ。01-01には「何かメッセージが出たら、慌てず `F12` か Reset をまず試す」という使い方の記述があります |
| `F3`(終了) | そのプログラムやメニューを終わらせて、元の場所に戻る | [01-01](../part01/01-01-screen-and-keys.md) | 01-01本文。V3、著者は未確認 |
| `F12`(取り消し) | 今の画面の操作を取り消して、1つ前の画面に戻る | 01-01 | 同上 |
| `SysReq` | 暴走したジョブを止める入口(押して `2`(ジョブの終了)を選ぶ、と 03-05 は書いています) | [03-05](../part03/03-05-loops.md) | 03-05本文。**実機では試していません**(V3)。03-05は「00-03で学んだキー」と書いていますが、00-03の表には `SysReq` が載っていません(この食い違いは未解決です) |
| `System Request`(または `Attn`) | 暴走に気づいたときに押し、`2`(ジョブの表示)から該当ジョブを選んで `ENDJOB` する | [04-01](../part04/04-01-first-program.md) | 04-01本文。V3、著者は未確認。上の `SysReq` の説明(`2`の意味)は03-05と04-01で異なっています。どちらも未確認なので、実際の画面に出るメニューの文言を読んでから選んでください |
| `Sys Req` | 入力待ちでコマンド行が使えないジョブに、システム要求で割り込んで別のコマンドを動かす手段の候補 | [06-09](../part06/06-09-exception-handling-debugging.md)・[06-11b](../part06/06-11b-maintenance-screen-locking.md) | 両レッスンとも「使えなければ別セッションを用意する」という代替を添えており、動作は確認していません |
| `Attention`・`SYSREQ` | ジョブを止める候補 | [09-05](../part09/09-05-external-api-adapter-mock.md) | 09-05本文に「これも実機では試していません」とあります(未検証) |

## 3. SEU(ソース入力ユーティリティー)のキー

出典は[05-01](../part05/05-01-legacy-intro.md)の「参考: SEU の行コマンド」と、[03-01](../part03/03-01-cl-skeleton.md)・[01-07](../part01/01-07-pdm-and-seu.md)です。行コマンドの綴りと `F13`〜`F17` の役割は、IBM公式マニュアル「ADTS for AS/400: Source Entry Utility」(SC09-2605-00)で確認した内容です。**実機の5250画面での操作は、著者は確認していません(V3)。**

RPG III を通らないルートでは、05-01 は読まないので、SEU の基本操作(`COLS`・`F4` プロンプトなど)は [04-21](../part04v/04-21-fixed-form-skeleton.md) の「SEU についての注意」で読んでください。この節の表そのものは、ルートでもそのまま使えます。

### ファンクション・キー

| キー | 役割 | 根拠 |
|---|---|---|
| `F3` | 保存して(確認画面を経て)SEUを終了する。メンバーを新規作成した場合、何も入力せずに抜けると保存されない | 01-07。学習者の実測([M])と一次資料 |
| `F13` | 編集セッション全体の既定値を変更する画面を開く | 05-01。一次資料(画面の中身は実機未確認) |
| `F14` | 検索・置換のオプション画面(Find/Change Options)を開く | 03-01・05-01。一次資料で確認 |
| `F16` | 検索の実行・繰り返し | 03-01・05-01。一次資料 |
| `F17` | 置換の実行・繰り返し | 05-01。一次資料 |

`F15` は検索キーではありません。03-01は2026-09-27に `F15` から `F14` へ訂正済みで、一次資料では `F15` は無関係の Browse/Copy Options です。ただし05-01の「参考: SEU の行コマンド」の冒頭には、訂正前の「`F15`(検索)」という記述がまだ残っています(この付録の担当外のため未修正、報告事項です)。

### 行コマンド(シーケンス番号欄に入力する)

| 行コマンド | 意味 |
|---|---|
| `C` / `Cn` / `CC` | コピー(この行 / `n` 行 / 最初の `CC` から次の `CC` までの範囲) |
| `M` / `Mn` / `MM` | 移動(コピー元は削除される) |
| `A` | コピー・移動の対象を、この行の**後**に置く |
| `B` | コピー・移動の対象を、この行の**前**に置く |
| `D` / `Dn` / `DD` | 削除(この行 / `n` 行 / `DD` で挟んだ範囲) |
| `RP` / `RPn` | この行を直後に複製する(`RPn` は `n` 回) |

根拠は05-01の表です。一次資料の「Summary of Line Commands」表と綴りが一致することを確認済みです(V3の画面操作は未確認)。

### SEUを抜けるときの注意

- 保存せずに抜けたいときは、コマンド行に `CANCEL`(短縮形 `CAN`)を入力して Enter を押します(05-01の演習12)。変更ありのまま実行すると確認の Enter を求められ、取り消したい場合は `F12` でその確認自体を取り消せる、と05-01は書いています。
