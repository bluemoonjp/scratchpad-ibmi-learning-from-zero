# 第6部 RPG IV 完全自由形式

## この部の目標

第4〜5部で読み書きした RPG III を出発点に、**RPG IV の完全自由形式(`**FREE`)を主力言語として書ける**ようになります。`CVTRPGSRC` による橋渡しから始め、サブプロシージャー・組み込み関数(BIF)・データ構造・配列・ファイル入出力・例外処理・サブファイル・帳票(印刷装置ファイル)・埋め込みSQLまで、実務でRPG IVプログラムを書くのに必要な一通りの技法を身につけます。

## 前提となる状態

第5部までの内容(`TXSETUP`/`TXLEGACY` によるサンプル・データベースと旧システムの投入)が済んでいること。この部からは `QRPGLESRC`(RPG IV 用のソース物理ファイル)を新たに使い始めます。

## 道具

5250(コンパイル・実行・画面確認)。ソース取り込みは SSH(`CPYFRMSTMF`)を使うレッスンが大半です(接続の粒度はレッスンごとに異なります。各レッスンの案内文の「同時接続数」欄を参照してください)。06-13 以降は SQL(`STRSQL`)も使います。

## この部で自分たちが作る道具

新規の道具はありません。`TXCHECK`(第5部で導入済み)を、この部のチェックポイント(06-15)で `*CMD` 形で実際に実行します。

## 観測方法

`WRKSPLF`(印刷結果)、`DSPJOBLOG`(ジョブ・ログへのメッセージ)、画面そのもの(対話プログラム)。06-12 以降は `CHGCMD`・`F4` によるコマンドのCPP差し替えも扱います。

## この部で扱わないこと

- モジュール・サービス・プログラム・活性化グループ(ILE の本格的な話。第7部)。
- VS Code / Code for IBM i(06-02。GUI操作中心のため公開を保留しています)。
- SQLのパフォーマンス・チューニング(インデックス・Visual Explain の存在だけ06-14で触れ、手を動かす演習はありません)。

## 同時接続数

基本は5250×1です。SSHでのソース取り込みが必要なレッスンは、都度接続し直す形と1回の接続でまとめて行う形の両方があります(各レッスンの案内文を参照)。06-11b・06-09 の一部演習(別セッションからのロック競合を試す)では5250×2を使うことがあります。

## 容量の予算

この部で作るオブジェクトはいずれも小さなプログラム・DDS・SQLRPGLEで、容量を気にする場面はありません。06-14b は `QTEMP` 上に作業用テーブルを作りますが、ジョブ終了で自動的に消えます。

## 出力が違うとき

- **印刷結果が `WRKSPLF` に出てこない**: この教材の検証ハーネス(非対話SSHジョブ)では、印刷装置ファイルへの出力が実スプール・ファイルにならないことが分かっています。学習者自身の5250対話セッションからの `CALL` では、通常どおり `WRKSPLF` で確認できます。
- **画面が期待と違う**: 06-04 以降の画面系レッスンは、コンパイル(V1)までは実機確認済みですが、対話的な実行(`EXFMT` での画面操作そのもの)は、この教材の検証ハーネスでは検証できません(各レッスンの実機メモを参照してください)。
- **06-11bを実施した場合の注意**: 06-11bの演習は共有テーブル `SHOHIM` の中身を書き換えます。06-15(チェックポイント)に進む前に、必ず `TXRESET` を実行してください。
