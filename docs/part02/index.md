# 第2部 データベースと教材の取り込み

## この部の目標

データベースの基礎概念を IBM i の用語で理解し、この教材(架空の商社のサンプル・データベース)を、自分の PUB400 アカウントに取り込みます。

## 道具

5250、02-04 から SSH(git)も使います。

## 観測方法

SQL の `SELECT` 結果。

## この部が終わった時点の状態

`TXSTATUS` で `DBVER=1` と表示される状態になります。

## この部で扱わないこと

DDL(SQL でのテーブル定義。第8部で扱います)、ジャーナルの管理。

## 同時接続数

5250 + SSH。
