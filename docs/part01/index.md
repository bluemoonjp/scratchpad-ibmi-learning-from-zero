# 第1部 5250 と基本コマンド

## この部の目標

5250 の画面操作に慣れ、オブジェクト・ライブラリー・ジョブ・メッセージという、IBM i の基礎概念を扱えるようになります。

## 道具

5250(ACS または tn5250j)。01-07 から PDM/SEU も使います。

## 観測方法

画面の最下行に出るメッセージと、`F1` で開くメッセージの詳細。

## この部で扱わないこと

`WRKACTJOB` のような管理系のコマンドは扱いません(付録Eで読み物として触れます)。

## 同時接続数

5250×1。
