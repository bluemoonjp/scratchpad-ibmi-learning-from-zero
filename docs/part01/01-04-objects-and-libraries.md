## なぜ学ぶか

IBM i では、プログラムもファイルもデータ域も、すべて「オブジェクト」という統一的な考え方で扱われます(00-01 で触れました)。ここでは、その具体的な調べ方と、自分が使える3つのライブラリーの役割を押さえます。以後のすべてのレッスンで、「今どのライブラリーに何を作っているか」を意識することになります。

## 新出

- オブジェクトの主な型(`*PGM`・`*FILE`・`*LIB` など)
- `<USER>1`・`<USER>2`・`<USER>B` という自分の3つのライブラリー
- `WRKOBJ`・`DSPOBJD`
- `DSPUSRPRF` の `MAXSTG`/`STGUSED`(容量)

## 説明(Windows / Linux との比較)

Windows のファイル・システムは、フォルダーの中にフォルダーを作れる「階層構造」です。IBM i の**ライブラリーは1階層しかありません。** ライブラリーの中にライブラリーを作ることはできず、ライブラリーはすべて `QSYS` という特別なライブラリーの直下に並びます。

### オブジェクトの主な型

| 型 | 意味 |
|---|---|
| `*PGM` | プログラム |
| `*FILE` | ファイル(物理ファイル・論理ファイル・表示装置ファイル・印刷装置ファイルなどをまとめて指す) |
| `*LIB` | ライブラリー |
| `*DTAARA` | データ域(小さな値を保存しておく場所) |
| `*MSGF` | メッセージ・ファイル |
| `*CMD` | コマンド |

「型」と、01-06 で学ぶ「属性(ファイルの中でも物理ファイルか論理ファイルか、など)」は別の情報です。ここでは、まず「型」で大分類できることを覚えてください。

### 自分の3つのライブラリー

PUB400 のアカウントには、標準で3つのライブラリーが割り当てられます。

| ライブラリー | 役割 |
|---|---|
| `<USER>1` | 現在の開発用。この教科書では主にここを使います |
| `<USER>2` | 本番役(第5部以降で使います) |
| `<USER>B` | 保存ファイル(バックアップ)の置き場 |

**サインオンした直後のライブラリー・リストに入っているのは `<USER>1` だけです。** `<USER>2` や `<USER>B` を使うには、明示的にライブラリー名を指定するか、ライブラリー・リストに追加する必要があります(01-05 で学びます)。

また、**`CRTLIB`(ライブラリーを新しく作る)コマンドは、PUB400 では使えません。** 実行すると `CPF9802` のようなメッセージで拒否されます。3つのライブラリーの中で工夫して進める、というのがこの環境の前提です。

## 実演

1. コマンド行に `WRKOBJ OBJ(<自分のユーザー名>1/*ALL)` と打ち、Enter を押す(`<自分のユーザー名>1` の部分は、00-02 で登録したユーザー名に `1` を付けたものに置き換えてください)。自分の `<USER>1` の中にあるオブジェクトが一覧表示されます。
2. 一覧の中から1つ選び、オプション `5`(表示)を指定して Enter を押す。`DSPOBJD` が実行され、そのオブジェクトの型や作成日時が表示される。
3. `F3` で戻る。
4. コマンド行に `DSPOBJD OBJ(QSYS/<自分のユーザー名>2) OBJTYPE(*LIB)` と打ち、Enter を押す。`<USER>2` ライブラリーそのものの情報(所有者や作成日時)が表示される。
5. 同様に `DSPOBJD OBJ(QSYS/<自分のユーザー名>B) OBJTYPE(*LIB)` で `<USER>B` も確認する。

> **オブジェクトの存在確認に `CHKOBJ` を使わない。** `CHKOBJ` はプログラムの中(CL プログラムなど)でしか使えないコマンドで、コマンド行に直接打つと失敗します。コマンド行から存在を確認したいときは、ここで使った `DSPOBJD` を使ってください。

## 同じ手順を別の対象で

1. コマンド行に `DSPUSRPRF USRPRF(*CURRENT)` と打ち、Enter を押す。自分のユーザー・プロファイルの情報が表示される。`MAXSTG`(最大記憶域)と `STGUSED`(使用中の記憶域)の値を確認し、記録する。
2. `WRKOBJ OBJ(<自分のユーザー名>1/Q*) OBJTYPE(*FILE)` を実行し、`Q` で始まるソース物理ファイル(`QCLSRC` など)を確認する。

## 出会うメッセージID

| ID | 状況 |
|---|---|
| CPF9802 | `CRTLIB` を実行したとき(権限がなく作成できない) |

## 演習

1. `<USER>1`・`<USER>2`・`<USER>B` のそれぞれについて、`DSPOBJD OBJ(QSYS/<USER>x) OBJTYPE(*LIB)` を実行し、所有者と作成日時を記録してください。
2. `DSPUSRPRF USRPRF(*CURRENT)` で確認した `STGUSED` の値を、メッセージID帳や進捗メモの近くに書き留めてください(後のレッスンで容量の増減を確認する際に使います)。
