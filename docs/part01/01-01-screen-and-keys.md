# 01-01 画面とキーの基本

## ゴール

- コマンドを実行し、入力禁止になった画面を解除できる。
- `More...` と `Bottom` を見分け、ページ送りができる。
- `SIGNOFF` で安全に終了できる。

## ウォームアップ

前のレッスン(00-03)で、サインオンとパスワード変更をしました。今日はサインオンした状態から始めます。

## なぜ学ぶか

5250 は、この後すべてのレッスンで使う画面です。ここで基本操作を固めておかないと、コマンドの内容を学ぶ以前の場所でつまずき続けることになります。

## 新出

- 画面単位の送信(`===>` の行に打って Enter)
- Reset(入力禁止の解除)
- `F3`(終了)と `F12`(取り消し)
- ページ送り(`More...` と `Bottom`)
- `SIGNOFF`

## 説明(Windows / Linux との比較)

Linux のシェルは、1行打って Enter を押すと、その1行だけが処理されます。5250 は違います。**画面全体が1つの入力フォームで、Enter を押すと画面全体が一度に送信されます。** コマンド行(`===>` と表示されている行)に文字を打ち、Enter を押すと、そのコマンドが実行されます。

### 入力禁止とReset

何か操作をしていると、キーボードが「入力禁止」になることがあります(通常は画面の右下あたりに、鍵のマークや `X II` のような表示が出ます)。これは異常ではなく、**ホストが処理中か、エラーで応答待ちになっている**サインです。この状態のときは、いくら文字を打っても入力されません。

**Reset キーを押すと解除されます。** ACS の既定では左 Ctrl キーが Reset に割り当てられています(00-03 参照)。

### F3 と F12 の違い

- `F3`(終了): そのプログラムやメニューを終わらせて、元の場所に戻ります。
- `F12`(取り消し): 今の画面の操作を取り消して、1つ前の画面に戻ります。

似ていますが、`F3` の方が「先へ進んで終わる」、`F12` の方が「今の操作をやめて戻る」という違いがあります。使い分けは、実際に両方を試して体で覚えるのが一番です。

### ページ送り

一覧のような画面では、1画面に入りきらない情報は複数ページに分かれます。画面の下の方に `More...` と出ていれば、まだ続きがあります。`Bottom` と出ていれば、それが最後のページです。Page Down で次のページに進みます。

## 実演

1. コマンド行に `DSPLIBL` と打ち、Enter を押す。自分のライブラリー・リストが表示される。
2. `F3` を押して、コマンド行に戻る。
3. コマンド行に `DSPSYSVAL SYSVAL(QCCSID)` と打ち、Enter を押す。システム値 QCCSID(文字コードの設定)が表示される。
4. `F12` を押して、コマンド行に戻る。
5. コマンド行に `WRKOBJ OBJ(QSYS/QD*) OBJTYPE(*ALL)` と打ち、Enter を押す。QSYS ライブラリーの `QD` で始まるオブジェクトが一覧表示される。件数が少ないので `Bottom` まで簡単に到達できるはずです。
6. Page Down を押して `Bottom` まで進み、それ以上ページがないことを確認する。
7. `F3` でコマンド行に戻る。

## 同じ手順を別の対象で

1. `DSPSYSVAL SYSVAL(QDATE)`(システム日付)を表示し、`F3` で戻る。
2. `DSPSYSVAL SYSVAL(QTIME)`(システム時刻)を表示し、`F12` で戻る。
3. `WRKOBJ OBJ(QSYS/QC*) OBJTYPE(*ALL)` を実行し、`QD*` のときと件数を比べる。ページ送りで `Bottom` まで進む。

## 出会うメッセージID

このレッスンでは意図的なエラーは起こしませんが、もし打ち間違えたら、画面最下行にメッセージが出ます。次のレッスン(01-03)で、メッセージの読み方を詳しく学びます。今は「何かメッセージが出たら、慌てず `F12` か Reset をまず試す」とだけ覚えてください。

## 出力が違うとき

- キーボードが反応しない → 入力禁止になっていないか確認し、Reset を押す。
- `DSPSYSVAL SYSVAL(*ALL)` のように、`*ALL` を指定して一度にすべてのシステム値を見ようとするとエラーになります(PUB400 では許可されていません)。1つずつ指定してください。

## 演習

1. `DSPSYSVAL SYSVAL(QCCSID)` と `DSPSYSVAL SYSVAL(QDATE)` を、それぞれ `F3` で戻る場合と `F12` で戻る場合の両方で試し、違いを自分の言葉で説明してください。
2. `WRKOBJ OBJ(QSYS/QD*) OBJTYPE(*ALL)` を実行してから `SIGNOFF` と入力して Enter を押し、サインオフしてください。その後、再度サインオンし直してください。
