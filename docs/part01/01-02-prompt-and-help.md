## なぜ学ぶか

IBM i には数千のコマンドがあり、パラメーターも多岐にわたります。すべて暗記するのは現実的ではありません。**`F4` でパラメーターの候補を出しながら組み立てる**のが、実務でも標準的なやり方です。また、コマンド名には規則があるため、知らないコマンドでも名前から意味を推測できることがよくあります。

## 新出

- `F4`(プロンプト)
- `F11`(表示の切り替え)
- `F9`(全パラメーター表示、および直前のコマンドの呼び出し)
- `F1`(ヘルプ)
- コマンド名の「動詞+目的語」規則
- `SLTCMD`(コマンドを名前で検索する)

## 説明

### F4 プロンプト

コマンド名だけを打って `F4` を押すと、パラメーターを選んで入力する画面が開きます。例えば `DSPLIB` とだけ打って `F4` を押すと、ライブラリー名を入力する欄が出ます。**パラメーターの正確な綴りやキーワードを覚えていなくても、`F4` の画面上でカーソルを合わせて `F4` を押せば、さらに候補が出ることもあります。**

`F4` の画面で `F11` を押すと、表示が切り替わります(パラメーターの意味の説明と、実際のキーワードの表示を切り替える、など)。`F9` を押すと、既定では省略されている詳細なパラメーターまで含めて全部が表示されます。

### F1 ヘルプ

カーソルをパラメーターの上に置いて `F1` を押すと、そのパラメーターの説明が表示されます。コマンド名の上で `F1` を押すと、コマンド全体の説明が表示されます。

### コマンド行の F9(履歴)

コマンド行(何も実行していない状態)で `F9` を押すと、**直前に実行したコマンドが呼び戻されます。** さらに `F9` を押すと、もっと前のコマンドにさかのぼれます。打ち間違いを一から打ち直さずに直せるので、日常的によく使います。

### コマンド名は「動詞+目的語」

IBM i のコマンドの多くは、3文字前後の「動詞」と、対象を表す「目的語」の組み合わせでできています。

| 動詞 | 意味 | 例 |
|---|---|---|
| `DSP` | Display(表示する) | `DSPLIB`(ライブラリーを表示) |
| `WRK` | Work with(一覧して操作する) | `WRKLIB`(ライブラリーを一覧する) |
| `CRT` | Create(作成する) | `CRTLIB`(ライブラリーを作成する) |
| `CHG` | Change(変更する) | `CHGLIB`(ライブラリーを変更する) |
| `DLT` | Delete(削除する) | `DLTLIB`(ライブラリーを削除する) |
| `ADD` | Add(追加する) | `ADDLIBLE`(ライブラリー・リストに追加する) |
| `RMV` | Remove(取り除く) | `RMVLIBLE`(ライブラリー・リストから取り除く) |

`SIGNOFF`・`CALL`・`GO` のように、この規則に当てはまらない例外もあります。基本は「まず動詞と目的語を分けて考え、推測して `F4` や `F9`(コマンド名の入力補完)で確認する」という進め方です。

### コマンドを名前で検索する

コマンド名の一部しか思い出せないときは、`SLTCMD` コマンドが使えます。`SLTCMD CMD(WRK*)` のように打つと、`WRK` で始まるコマンドの一覧が出ます。

### IBM Documentation で調べる

`F1` で表示される説明で足りないときは、Web で IBM Documentation(IBM i 7.5)のコマンド・リファレンスを調べます。検索エンジンで「コマンド名 IBM i」と検索すると、たいてい最初の方に出てきます。バージョンを選べる場合は、必ず **7.5** を選んでください(古いバージョンの説明はパラメーターが違うことがあります)。

## 実演

1. コマンド行に `DSPSYSVAL` とだけ打ち、`F4` を押す。パラメーター入力画面が開く。
2. `SYSVAL` の欄に `QCCSID` と入力し、Enter を押す。
3. `F3` で戻る。
4. コマンド行に `WRKSPLF` とだけ打ち、`F4` を押す。`F9` を押して、詳細なパラメーターまで表示させる。`F3` で戻る。
5. コマンド行に `DSPLIB` とだけ打ち、`F4` を押す。ライブラリー名の欄にカーソルを置いて `F1` を押し、説明を読む。`F3` で戻る。
6. コマンド行に `SLTCMD CMD(WRK*)` と打ち、Enter を押す。`WRK` で始まるコマンドの一覧を眺める。`F3` で戻る。

## 演習

1. 次のコマンド名から、動詞と目的語を分けて意味を推測してください(実行して確かめてもかまいません)。
   - `CRTLIB`
   - `DLTLIB`
   - `WRKOBJ`
   - `CHGLIB`
   - `RMVLIBLE`

   <details><summary>解答</summary>

   - `CRTLIB` = Create + Library(ライブラリーを作成する)
   - `DLTLIB` = Delete + Library(ライブラリーを削除する)
   - `WRKOBJ` = Work with + Object(オブジェクトを一覧して操作する)
   - `CHGLIB` = Change + Library(ライブラリーを変更する)
   - `RMVLIBLE` = Remove + Library List Entry(ライブラリー・リストから取り除く)

   </details>

2. 次の意味のコマンド名を、規則から推測してください(`SLTCMD` で確認してもかまいません)。
   - 「オブジェクトを表示する」
   - 「メッセージを送る」

   <details><summary>解答例</summary>

   - `DSPOBJD`(Display Object Description)
   - `SNDMSG`(Send Message)

   </details>

3. コマンド行で、何か短いコマンド(例: `DSPSYSVAL SYSVAL(QDATE)`)を3つ続けて実行してください。その後、`F9` を3回押して、3つ前まで履歴をさかのぼれることを確認してください。
