# 第0部 はじめに

## この部の目標

この教科書の使い方を知り、PUB400 のアカウントを取得して、5250 エミュレーターでサインオンできるようになります。

## 道具

Web ブラウザーと、5250 エミュレーター(ACS または tn5250j)。

## 観測方法

「サインオン画面まで届くか」で確かめます。

## この部で扱わないこと

コマンドの操作そのものは第1部から始めます。この部は準備だけです。
