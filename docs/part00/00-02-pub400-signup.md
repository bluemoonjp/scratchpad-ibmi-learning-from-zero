## 説明

### メール・アドレスの注意(重要)

PUB400 からのメール(登録確認・パスワード通知)は、送信元 IP アドレスがスパム・ブロックリストに登録されているため、**Gmail・Outlook(Hotmail)・Yahoo・iCloud には届きません。** これらをメール転送先にしている独自ドメインのアドレスも同様に届かない場合があります。登録前に、それ以外のメール・アドレス(プロバイダー提供のもの、大学のアドレス等)を用意してください。

### 登録の流れ

1. <https://pub400.com/> の登録ページ(Sign Up)を開く。
2. メール・アドレスと、希望するユーザー名を入力する。
3. 行動規範("I have read these behaviour rules")に同意するチェックボックスを入れる。
4. 確認メールが届くので、リンクを開いて登録を完了する。
5. 「PUB400 - your user profile」という件名のメールが届き、ユーザー ID と初期パスワードが記載されている。

**この初期パスワードは、届いた時点で既に期限切れの状態になっています。** ACS(IBM i Access Client Solutions)は期限切れのパスワードをサインオン画面で変更する機能を持っていないため、初回のパスワード変更は tn5250j のような別の5250クライアントで行う必要があります。詳しくは次のレッスン(00-03)で扱います。

### PUB400 は「遊び場」であって「本番機」ではない

PUB400 のトップページには、コミュニティー規約として次のようなことが明記されています。

- 1人につき1つのプロファイル。複数アカウントを作ったり、商用の環境として使ったりしない。
- 同一 IP からの接続数には、**明確な上限**がある。
- 他のユーザーのライブラリーには、通常アクセスできない。
- **定期バックアップは行われない。** 「これは遊び場である」と明記されている。
- 他のユーザーに迷惑をかけない("DO NOT NAG OTHER USERS!")。

### 絶対にしてはいけないこと

2025年8月、複数ユーザーの全オブジェクトを走査する操作を行ったユーザーが、**アカウントだけでなく、そのメール・ドメイン全体をロックアウトされた**という事例が実際にありました。理由は「他人のシステムを乱すべきではない」というものです。

この教科書では、次のようなコマンド・操作は決して教えません。

- `WRKLIB *ALL` や `*ALLUSR` のように、自分以外のライブラリーやユーザーを対象にした総称検索
- 他ユーザーの名前を指定した操作
- `QGPL`(システム全体で共有される作業ライブラリー。約20万個のオブジェクトがある)を、絞り込みなしでページ送りすること

## 演習

「このコマンドを打ってよいか」を、理由とともに判断してください(解答は下の details を開く)。

1. `WRKLIB *ALL`(自分以外のライブラリーも含めて一覧する)

    <details><summary>解答</summary>

    してはいけません。自分のライブラリーだけを対象にする(例: `WRKLIB <USER>*`)べきです。

    </details>

2. `DSPLIBL`(自分のライブラリー・リストを表示する)

    <details><summary>解答</summary>

    してよいです。自分自身の情報しか見ません。

    </details>

3. 短時間に何度も SSH 接続を繰り返して、うまくいく組み合わせを探す

    <details><summary>解答</summary>

    してはいけません。同一 IP からの接続数には上限があり、認証の失敗が続くと IP ごと一時的に遮断されることがあります。1回で確実につながる設定を、あらかじめ確認してから接続してください(02-04 で詳しく扱います)。

    </details>
