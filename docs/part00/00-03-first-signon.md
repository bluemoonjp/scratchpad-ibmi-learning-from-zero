# 00-03 5250 エミュレーターと初回サインオン

> 所要時間: 60分 / 前提レッスン: 00-02 / 目標番号: 0(準備) / 観測方法: サインオン画面まで届くか / 道具: 5250 エミュレーター(ACS または tn5250j) / 同時接続数: 5250×1 / 作る・変えるオブジェクト: なし / DBVER: なし / 依存するプローブ: P02, P41 / PTF 依存: なし / 容量の目安: 0

## ゴール

- ホスト・コード・ページを 273 に設定して、PUB400 にサインオンできる。
- 期限切れの初期パスワードを変更できる。

## ウォームアップ

このレッスンには前提知識がいらないので、ウォームアップはありません。

## なぜ学ぶか

5250 は、この教科書の第1〜5部で使う唯一の画面です。最初にコード・ページの設定を誤ると、パスワードの記号が正しく送信されずサインオンできなかったり、後々まで記号化けに悩まされたりします。ここで正しく設定しておくことが、後のすべてのレッスンの前提になります。

## 新出

- 5250 エミュレーター(ACS / tn5250j)
- ホスト・コード・ページの概念
- Reset キー、Enter キー

## 説明(Windows / Linux との比較)

Windows のリモート・デスクトップや、Linux の SSH 端末は、比較的最近の技術です。5250 はそれよりずっと古い、**画面全体を1つの単位としてやり取りする**方式です。1文字打つたびに通信するのではなく、画面に必要な項目をすべて入力してから Enter を押すと、画面全体がまとめてホストに送られます。これは、5250 端末が生まれた1970年代当時、通信回線が遅く高価だったことの名残です。

### ポート番号

PUB400 への5250接続は、23番(平文)と992番(TLS 暗号化)で待ち受けています。**992番(TLS)を使うことを推奨します。** 23番は通信内容が暗号化されないため、初回のパスワード変更のような重要な操作には向きません。

### ホスト・コード・ページは 273

PUB400 のシステム全体の文字コード設定(QCCSID)は **273**(ドイツ語圏向けの EBCDIC)です。5250 エミュレーター側のホスト・コード・ページをこれに合わせないと、次のような問題が起こります。

- サインオン時にパスワードの記号が正しく送信されず、`CPF1120`(パスワードが無効)になることがある。
- `@` `[` `]` `!` `|` `~` `^` `{` `}` `\` などの記号が、送信・表示の際に別の文字化けした記号に置き換わる。

tn5250j はホスト・コード・ページの既定値が 37 であり、273 ではありません。**接続時に明示的に 273 を指定する必要があります。**

## 実演

### ACS(IBM i Access Client Solutions)を使う場合

1. ACS を入手する(IBMid でのサインインと、Java 8 以降が必要)。
2. 新しい5250セッションを作成し、システム名に `pub400.com`、ポートを 992(TLS)、ホスト・コード・ページを 273 に設定する。
3. 接続すると、サインオン画面が表示される。ユーザー ID と、メールで届いた初期パスワードを入力する。

**注意**: 初期パスワードは届いた時点で期限切れです。ACS はサインオン画面上でのパスワード変更をサポートしていないため、`MSGSY1008` のようなエラーで先に進めないことがあります。その場合は、次の tn5250j の手順で初回のパスワード変更だけを行い、その後 ACS に戻ってください。

### tn5250j を使う場合(初回のパスワード変更に必要)

1. tn5250j を起動し、新しい接続を作成する。
2. ホストに `pub400.com`、ポートに `992`(TLS)を指定する。
3. **ホスト・コード・ページを 273 に明示的に設定する**(既定値の 37 のままにしない)。
4. 接続すると、サインオン画面が表示される。ユーザー ID と初期パスワードを入力すると、「新しいパスワードを入力してください」という画面に進む。
5. 新しいパスワードを2回入力する。PUB400 のパスワード・レベルは 3 で、大文字・小文字を区別し、128文字まで使える。

## 主なキー(ACS の場合)

| 操作 | キー |
|---|---|
| Enter | PC の Enter |
| Reset(入力禁止の解除) | 左 Ctrl |
| New Line(改行のみ。Field Exit ではない) | 右 Ctrl |
| F13〜F24 | Shift+F1〜Shift+F12 |

これらのキー割り当ては ACS の既定設定によるものです。他のエミュレーターやキーボード配列では異なる場合があります。詳しくは [付録D](../appendix/d-keys.md) にまとめます(第10部の整備に合わせて作成します)。

## 出会うメッセージ ID

| ID | 原因 | 対処 |
|---|---|---|
| CPF1120 | パスワードが無効(コード・ページの不一致が原因のことが多い) | ホスト・コード・ページが 273 になっているか確認する |
| MSGSY1008(rc=24) | ACS が期限切れパスワードを変更できない | tn5250j 等、別の5250クライアントで変更する |

## 演習

1. ホスト・コード・ページを 273 にしてサインオンし、パスワードを変更する。
2. サインオンできたら、いったん `SIGNOFF` と入力して Enter を押し、サインオフする(コマンドの意味は01-01で学びます。今は「打ってサインオフできること」だけを確認します)。
3. 再度サインオンし直す。

## 実機メモ

- ポート番号(23/992)とコード・ページ 273 の必要性は、一次資料(PUB400 の FAQ)と、著者の実測に基づく確認済みの事実である(確認日: 2026-09-24、`docs/probes.md` 参照)。
- ACS が期限切れパスワードを変更できないこと、tn5250j の既定コード・ページが 37 であること、および表中のキー割り当ては、協力してくれた学習者による実測([M])に基づく。著者自身のこのセッションでは、ACS/tn5250j の画面遷移そのものは未確認(P41)。食い違いに気づいたら [Issue](https://github.com/bluemoonjp/scratchpad-ibmi-learning-from-zero/issues) で教えてください。
