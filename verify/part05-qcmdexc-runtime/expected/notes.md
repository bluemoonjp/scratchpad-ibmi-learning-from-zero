# part05-qcmdexc-runtime の期待値(未検証)

## ZA0510V(*PSSR/CHGDTAARA経路)

`za0510v.rpg` は `TABPCD` の最終要素を `P00006` から `P09999` に書き換えた
検証専用ソース(`za0510.rpg` 本体とはこの1点だけが違う。`docs/probes.md`で
diff検証済み)。`ZAIKOM` に実在する `P00006`(在庫22個)を読んだ回だけ
`LOKUP` が失敗し、`EXSR *PSSR` が発火して `CHGDTAARA DTAARA(*LDA (1 20))
VALUE('ZA0510 ERROR')` が実行されるはず。

**期待するVLDAの出力(ジョブ・ログ、VFYLOG経由)**:

```
VLDA: *LDA(1,20)=[ZA0510 ERROR        ]
```

(`'ZA0510 ERROR'` は12文字、`*LDA`の1-20桁目=20バイトなので、残り8バイトは
空白でパディングされるはず——`CHGDTAARA`のVALUEが宣言長より短い場合の
一般的な既定動作という前提に基づく推測で、この一般論自体は実機確認していない)。

**`RUNZA1V`ステップの扱いについて**: `*PSSR`は`ENDSR '*CANCL'`でプログラムを
打ち切る。これがCLの呼び出し元(このマニフェストの`TXLEGRUN`相当、
ラッパー自身)に何らかのエスケープ・メッセージを送るのか、それとも単に
制御を返すだけなのかは未確認(`RPG/400 Reference`は「プログラムを取り消す」
としか書いておらず、呼び出し元への影響は明記していない)。**`RUNZA1V FAILED`
というマーカーが出ても出なくても、それ自体は成否の判定材料にしない** —
唯一の証拠は上記のVLDA出力そのもの。
